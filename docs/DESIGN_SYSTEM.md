# DESIGN_SYSTEM — «Пиксельный угар»

**Статус:** v0.1. Источник истины для всего UI. Любое изменение внешнего вида начинается с правки этого файла и записи в «Истории изменений».
**Приоритет:** `PROJECT_BRIEF.md` (продукт) → `AGENTS.md` (правила работы) → этот файл (внешний вид). При конфликте не выбирай молча — зафиксируй конфликт в отчёте.

## 1. Концепция

Тёмный пиксельный «терминал ночного города»: карта Минска под сеточным HUD-оверлеем, один лаймовый акцент, данные подаются как биржевые тикеры (плотные цифры, дельты, мини-индикаторы). «Угар» живёт в деталях: глитч, шум, кривляющийся значок профиля, ироничные тексты.

Одна фраза: **серьёзные цифры, несерьёзная подача.**

## 2. Принципы

1. Читаемость и достоверность данных важнее стиля. Угар никогда не мешает прочитать цену, адрес или итог.
2. Угар — в деталях, структура — спокойная. Расположение элементов и навигация предсказуемы.
3. Один акцент (лайм). Второй цвет только для предупреждений и перерасхода.
4. Деньги — всегда табличные/моноширинные цифры и всегда с пометкой достоверности.
5. Неизвестное не равно нулю: «нет данных» выглядит иначе, чем «0 BYN».
6. Всё живёт на пиксельной сетке: кратно 4 dp, без градиентов, без размытых теней, без скруглений.
7. Не «AI-dashboard»: никаких стеклянных карточек, декоративных блоков без функции, огромных заголовков на каждом экране (см. `PROJECT_BRIEF.md` §10).

## 4. Токены

### 4.1 Цвет (предварительная оценка, не измерение макета)

| Токен | Значение | Назначение |
|---|---|---|
| `bg.base` | `#121414` | фон под картой, fallback |
| `surface` | `#1E1E1E` | верхняя панель, нижняя навигация, листы |
| `surface.raised` | `#262826` | карточки внутри листов, чипы |
| `line` | `#3A3F3A` | границы 2 dp |
| `grid` | `#7CB342` @ 8–12 % | сетка поверх карты |
| `accent` | `#7CB342` | лайм: иконки, активные состояния, попап |
| `accent.dim` | `#4F7A2B` | неактивный акцент, подписи |
| `on.accent` | `#10140C` | текст и иконки на лайме |
| `text.primary` | `#E8EDE0` | основной текст |
| `text.muted` | `#8C918A` | плейсхолдеры, вторичный текст |
| `warn` | `#FFB020` | оценка, близость к лимиту |
| `danger` | `#FF3B5C` | перерасход, ошибки |

Контраст приведённых пар — только оценка; перепроверить вычислением и тестами. Не опускаться ниже 4,5:1 для текста.

### 4.2 Типографика

Шрифты должны содержать кириллицу. **Проверить покрытие глифов до подключения**, лицензию OFL и наличие файлов в `assets/fonts/` (без загрузки из сети в рантайме).

| Роль | Шрифт | Правило |
|---|---|---|
| UI и текст | Pixelify Sans | 12 / 14 / 16 / 20 sp |
| Декор (логотип, короткие метки) | Press Start 2P | только 12 или 16 sp, не для текста и не для цен |
| Деньги и цифры | табличные цифры (`tabularFigures`), иначе VT323 | цены никогда не пропорциональным шрифтом |

Валюту писать текстом: `BYN`. Масштаб текста системы (до 1,3) не ломает вёрстку.

### 4.3 Геометрия

- Шаг сетки 4 dp; отступы `4 8 12 16 24 32`.
- Рамка 2 dp; радиус 0. Допустим «срезанный угол» 4 dp через `ClipPath`.
- Тени: нет. Единственное исключение — жёсткая пиксельная тень 4 dp на попапе.
- Минимальная зона нажатия 48×48 dp.
- Иконки рисуются на сетке 16×16 или 24×24, масштаб целым числом, `FilterQuality.none`.

## 5. Компоненты

Каждый компонент: один виджет в `lib/ui/pixel/` (или аналогичном месте, если в репо уже есть структура), без hardcoded цветов, шрифтов и отступов. Состояния: default, pressed, disabled, loading, error.

- **TopSearchBar.** Во всю ширину минус 24 dp поля, высота ≈ 44 dp, `surface`. Плейсхолдер «куда двигаем» (`text.muted`), справа «?» (помощь/о приложении). Фокус: рамка `accent` 2 dp.
- **BottomNav.** Плавающая панель с полями 24 dp, 4 вкладки: Карта (глобус), Поиск (лупа), Избранное (сердце), Профиль (кривляющаяся рожица). Активная вкладка — инверсия: лаймовый блок, тёмная иконка. Рожица меняет выражение по состоянию вечера (в бюджете / впритык / перерасход).
- **PixelMarker.** Контурный пин — обычное место. Заполненная иконка категории (в макете колба) — выбранное место. Номер в рамке — место в плане вечера. Кластер — квадрат с числом. *Допущение по макету, подтвердить у владельца.*
- **PlacePopupCard.** Лаймовый фон, тёмный текст: название (жирно), категория, адрес, кнопка закрытия «×» в тёмном квадрате справа сверху. Добавить: строку цены с `ProvenanceBadge`, кнопку «в вечер». Тап по карточке открывает полную карточку места.
- **EveningSheet** (новый, «биржевая» часть). Свёрнутый: полоса над навигацией — «ВЕЧЕР · 3 места · 142 / 200 BYN» и `BudgetMeter`. Развёрнутый: перетаскиваемый список остановок с ценой и бейджем достоверности, плечи маршрута (способ, расстояние, время, стоимость), итог на человека, остаток, дельта к прошлой версии со знаком.
- **BudgetMeter.** Сегментная шкала из блоков. Лайм до 80 %, `warn` 80–100 %, `danger` выше 100 % (один раз дрожит). Значение дублируется числом, не только цветом.
- **ProvenanceBadge.** Три состояния: `подтверждено` (лайм, сплошная рамка), `оценка` (amber, пунктирная рамка, «≈»), `нет данных` (серый, «—»). Рядом возраст данных («3 дня назад») и источник по тапу.
- **FilterChip.** Прямоугольный чип 2 dp; выбранный — инверсия.
- **Buttons.** Primary: лайм + `on.accent`. Secondary: контур 2 dp. Destructive: `danger`-контур.
- **RouteLine.** Ступенчатая линия 4 dp, пунктир по режиму: пешком — точки, транспорт — штрихи, авто/такси — сплошная. Без сглаживания.
- **Состояния экранов.** Загрузка: пиксельный индикатор, подпись одной строкой. Пусто и ошибка: сначала понятный смысл, потом шутка, всегда кнопка действия («ещё раз», «сбросить фильтры»).

## 6. Стиль карты

- Подложка: карта Минска, затемнённая и слегка зелёная. Затемнение накладывается поверх тайлов, сами тайлы не обрабатываются и не кэшируются сверх лицензии.
- Сетка: ячейка 24 dp, линии `grid`; поверх карты, не перехватывает жесты.
- «Сканер»: одна тонкая вертикальная линия 1 dp (`accent` @ ≈ 35 %), медленно ходит по экрану; выключается при «уменьшить движение».
- Атрибуция провайдера карт остаётся видимой и не перекрывается панелями.
- **До применения затемнения и оверлея проверить условия провайдера** (разрешены ли тонирование и наложения, требования к атрибуции и кэшу). Результат записать в ADR.

## 7. Угар-слой (бюджет эффектов)

Разрешено:

- глитч-сдвиг на тап ≤ 200 мс; шум и скан-линии CRT на фоне панелей при ≤ 6 % непрозрачности;
- дрожание `BudgetMeter` при перерасходе (один раз); кривляющаяся рожица в навигации;
- стикер-бейджи («18+», «новое», «дёшево»);
- ироничные тексты.

Запрещено:

- любые эффекты на тексте цен, адресов, итогов; мерцание чаще 3 раз в секунду;
- постоянная анимация в списках; больше одной фоновой анимации на экран;
- эффекты, которые нельзя отключить: при «уменьшить движение» остаются только статичные.

## 8. Тексты

Смысл первым, шутка вторым. Шутка не заменяет объяснение ошибки.

| Ситуация | Пример |
|---|---|
| Поле поиска | куда двигаем |
| Загрузка | греем кружки… |
| Пустой список | пока пусто. добавь место в вечер |
| Нет данных о цене | цена: нет данных |
| Оценка цены | ≈ 25–40 BYN (оценка) |
| Перерасход | +18 BYN сверх бюджета. убрать место или поднять лимит |
| Нет сети | нет связи. показаны сохранённые места, цены могли устареть |
| Ошибка провайдера карт | карта не отвечает. попробуй ещё раз |

## 9. Доступность

- Контраст текста ≥ 4,5:1; состояние никогда не передаётся одним цветом.
- Масштаб текста до 1,3 без обрезки; экраны 360×800 и 393×852.
- Семантические подписи у иконок-кнопок; порядок фокуса логичен.
- «Уменьшить движение» отключает сканер, глитч, дрожание.

## 10. Реализация (Flutter)

- Токены — в одном месте темы (`ThemeExtension`), доступ через контекст. Прямые `Color(0x…)`, `TextStyle(fontFamily…)`, магические отступы вне темы запрещены.
- Иконки: перерисовать макетные (глобус, лупа, сердце, рожица, колба, пин, «×», «?») на сетке 16×16/24×24 в SVG или спрайт. Если берётся готовый набор, проверить лицензию.
- Golden-тесты для каждого компонента в основных состояниях. Скриншоты ключевых экранов в `docs/design/screens/`.
- Не менять бизнес-логику при перекраске. Логика расчётов не живёт в виджетах.
